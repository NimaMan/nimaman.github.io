# nimamanaf.com

Public personal website for `nimamanaf.com`.

This project is intentionally public-only. It builds to static HTML with Astro and does not include login, dashboard, terminal, Ralph, host filesystem mounts, or other private tools.

## Architecture

- `src/pages/` contains the public routes.
- `src/content/posts/` contains Markdown articles.
- `src/data/site-data.json` contains structured homepage content.
- `public/static/` contains images, GIFs, and page JavaScript copied into the deployed site.
- `src/styles/site.css` loads ordered Meridian CSS modules; `astro.config.mjs`
  adds local heading permalinks through `src/lib/rehype-heading-anchors.mjs`.
- `dist/` is generated by `npm run build` and should not be committed.

Public routes:

- `/`
- `/posts`
- `/posts/<slug>`
- `/static/*`

Private device and terminal tooling belongs in:

```text
/home/nima/code/tools/device_terminal_control/kopru
```

The Kopru terminal service is the replacement home for the old private website terminal/dashboard surface.

## Hosting and deploy

GitHub Pages serves the `gh-pages` branch of `origin` directly at `nimamanaf.com` (custom
domain through the `CNAME` file). There is no build workflow: deploying is manual. The source
lives on the `aesthetic-redesign` branch; `gh-pages` holds only the built `dist/` output.

1. Commit the source change on `aesthetic-redesign` and push it.
2. Build with Node 22 or newer (Astro 6 refuses older versions):

   ```bash
   export PATH="$HOME/.nvm/versions/node/v22.22.0/bin:$PATH"
   npm run build
   ```

3. Check out the published branch in a temporary worktree outside the repository and copy
   the build over it:

   ```bash
   git fetch origin
   git worktree add --detach <temporary-folder>/gh-pages-deploy origin/gh-pages
   rsync -a --delete --exclude=.git dist/ <temporary-folder>/gh-pages-deploy/
   ```

4. In that worktree, run `git status --short` and confirm that only the pages you meant to
   change are listed and that `CNAME` and `.nojekyll` are still present (both come from
   `public/`). Then:

   ```bash
   git add -A
   git commit -m "Deploy: site"
   git push origin HEAD:gh-pages
   ```

5. Remove the worktree (`git worktree remove <temporary-folder>/gh-pages-deploy`) and update
   the local branch (`git fetch origin gh-pages:gh-pages`).
6. GitHub Pages takes up to a few minutes to serve a push. Fetch the live page and check for
   a sentence that only the new version contains.

Pushes over SSH to GitHub sometimes fail with "Permission denied (publickey)"; retry.
HTML comments in a post's Markdown are shipped in the page source, so keep private notes out
of them.

## Private Services

Do not add private routes back to this project. Private tools should run behind Kopru/Tailscale or another explicit access layer, and should publish links through Kopru's service registry when needed.
