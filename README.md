# nimamanaf.com

Public personal website for `nimamanaf.com`.

This project is intentionally public-only. It builds to static HTML with Astro and does not include login, dashboard, terminal, Ralph, host filesystem mounts, or other private tools.

## Architecture

- `src/pages/` contains the public routes.
- `src/content/posts/` contains Markdown articles.
- `src/data/site-data.json` contains structured homepage and CV content.
- `public/static/` contains images, GIFs, and page JavaScript copied into the deployed site.
- `dist/` is generated by `npm run build` and should not be committed.

Public routes:

- `/`
- `/posts`
- `/posts/<slug>`
- `/cv`
- `/static/*`

Private device and terminal tooling belongs in:

```text
/home/nima/code/tools/device_terminal_control/kopru
```

The Kopru terminal service is the replacement home for the old private website terminal/dashboard surface.

## Local Development

```bash
npm install
npm run dev
```

Astro will print the local development URL.

## Build

```bash
npm run build
```

The production site is written to:

```text
dist/
```

Preview the built output locally:

```bash
npm run preview
```

## Hosting

Host `dist/` on a static host such as Cloudflare Pages, Netlify, Vercel, GitHub Pages, or a simple web server.

For Cloudflare Pages, use:

```text
Build command: npm run build
Output directory: dist
```

Then point DNS for `nimamanaf.com` and `www.nimamanaf.com` at the chosen host.

## Private Services

Do not add private routes back to this project. Private tools should run behind Kopru/Tailscale or another explicit access layer, and should publish links through Kopru's service registry when needed.
